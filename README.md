## Description

This project implements the **Subset Construction** algorithm presented in Kozen 1997, Lecture 6. It converts a Non-Deterministic Finite Automaton (NFA) into an equivalent Deterministic Finite Automaton (DFA).

The program reads one or more NFAs from standard input, builds the DFA by generating only the reachable subsets of NFA states, and prints for each case the initial state, the final states, and the transition table of the DFA.

## Input Format

The input consists of one or more cases.

### Step 1: Number of Cases

The first line contains an integer `c > 0` indicating the number of cases.

### Step 2: Number of States

For each case, a line contains an integer `n > 0` representing the number of NFA states.

The states are identified as:

```text
1, 2, 3, ..., n
```

### Step 3: Initial States

The next line contains the initial states of the NFA, separated by spaces.

### Step 4: Alphabet

The next line contains the alphabet symbols, separated by spaces.

The alphabet symbols are lowercase letters of the Latin alphabet.

The order of the symbols is preserved in the transition table.

### Step 5: Final States

The next line contains the final states of the NFA, separated by spaces.

### Step 6: Transition Table

The next `n` lines contain one transition-table row for each state, in order.

Each row starts with the state number, followed by one entry for each alphabet symbol, in the same order as the alphabet line.

The empty set is represented by `0`.

Sets of states are written using `{` and `}`, with elements separated by spaces.

### Example Input

```text
1
5
3 5
a b
1 4
1 {1 5} 0
2 {1} 0
3 {2 4} 0
4 0 {5}
5 {1 5} {4}
```

## Output Format

For each case, the program prints:

1. The initial state of the DFA.
2. The final states of the DFA.
3. The transition table of the DFA.

DFA states are represented by the subsets of NFA states that they contain.

The empty subset is represented by `0`. It is a dead state whose transitions lead back to itself for every alphabet symbol.

Only reachable DFA states are generated by the Subset Construction algorithm.

### Example Output

For the input above:

```text
Initial state: {3 5}
Final states: {1 2 4 5} {4} {1 5} {4 5}
State      a          b
{3 5}      {1 2 4 5}  {4}
{1 2 4 5}  {1 5}      {4 5}
{4}        0          {5}
{1 5}      {1 5}      {4}
{4 5}      {1 5}      {4 5}
0          0          0
{5}        {1 5}      {4}
```

## Algorithm

1. The set of initial states `S` of the NFA becomes the initial state of the DFA.
2. For each DFA state `T`, which is a subset of NFA states, and each alphabet symbol `a`, the program computes the union of the NFA transitions on `a` from every state in `T`.
3. If the resulting subset has not been processed before, it is added as a new DFA state.
4. The process continues until there are no new reachable subsets.
5. A DFA state is final if its subset contains at least one final state of the NFA.

### Worked Example

Starting from `{3 5}` with the example NFA:

- On `a`: `δ(3,a) ∪ δ(5,a) = {2 4} ∪ {1 5} = {1 2 4 5}`
- On `b`: `δ(3,b) ∪ δ(5,b) = ∅ ∪ {4} = {4}`

The new states `{1 2 4 5}` and `{4}` are then processed in the same way until no new reachable subsets appear.

A DFA state is final if it contains at least one final state of the NFA. In this example, the NFA final states are `1` and `4`.

### Complexity

In the worst case, the DFA can contain up to `2^n` states, where `n` is the number of NFA states. The implementation generates only reachable subsets. In the example above, 7 reachable DFA states are generated out of 32 possible subsets.
